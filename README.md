# Parkinson's Voice Research

Exploratory Parkinson's voice and speech research. Not a clinical diagnostic tool.

## Pick up the work

1. Clone this repository.
2. Use Python 3.14 and install the project dependencies.
3. Dataset files are in `data/raw/`.
4. Run scripts from the repository root. Some scripts still use the original author's local dataset paths; update those paths for your machine before running them.
5. Keep new experiments in separate output folders and preserve existing results.

The Italian VA1 baseline used participant-level five-fold cross-validation (29 participants) and reported ROC-AUC 0.917 and balanced accuracy 0.900. These are exploratory internal-validation results, not external validation.
