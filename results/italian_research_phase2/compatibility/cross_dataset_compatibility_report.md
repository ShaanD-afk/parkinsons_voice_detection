# English voice dataset compatibility investigation

No external dataset was downloaded, merged with ItalianPVS, or used for feature extraction or model training. Local directories were inventoried; documentation was checked for the candidate datasets. The machine-readable summary is `cross_dataset_compatibility_matrix.csv`; local file observations are in `local_dataset_inventory.csv`.

## Cross-dataset implementation rules

Potentially portable, if implemented identically from raw audio and validated, are F0 summaries on voiced frames, voiced-frame proportion, RMS-relative activity/pause summaries, and carefully defined HNR. Vowel formants need matched bandwidth/sample-rate and comparable vowel context. Jitter/shimmer require sustained, stable phonation and identical cycle-detection settings. CPP/CPPS is excluded until a validated implementation and matching procedure exist. Connected-speech comparisons require verified task materials/transcripts if content-dependent features are used.

No feature-name equality is treated as measurement equivalence: different software, recording bandwidth, hardware, prompt, recording environment, and participant aggregation can change the quantity. The next suitable cross-language milestone is a metadata/permissions lock plus matched-task measurement protocol, starting with sustained /a/ on raw audio (ItalianPVS and Figshare or mPower only after license/access confirmation). MDVR-KCL should remain a separate connected-speech exploratory corpus.
