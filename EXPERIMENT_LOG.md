- **Configuration:** mono PCM input; native-16-kHz recordings used for primary feature extraction. Five first-vowel codes, 17 HC and 12 PD participants each (145 recording-task rows). Praat Burg formants used fixed 5 kHz maximum-formant setting. Primary group family: median F0, local jitter, local shimmer, and mean HNR across five vowels (20 contrasts); participant bootstrap effect intervals and Mann-Whitney tests with Holm correction. ## `CROSS-LANGUAGE-GENERALISATION-V1-20261031` — completed exploratory generalisation experiment

- **Question:** Do participant-level sustained-vowel features and classical disease classifiers generalize between ItalianPVS VA1 and an independent Figshare `/a/` phone-phonation dataset, and can features identify dataset origin after diagnosis-count matching?
- **Pre-run inspection:** Recorded Git status in `results/cross_language_generalisation_v1/logs/git_status_before.txt`; inspected project status/decisions/log, final research reports and tables, cohort manifests, VA1 feature definitions, FILE CODES wording, Figshare metadata, and prior results. The Italian codebook states “2 phonation of the vocal ‘a’”; Figshare documents prolonged `/a/` by telephone. Figshare language is not established. Thus the valid scope is cross-dataset sustained `/a/` comparison, not confirmed cross-language transfer.
- **Inputs/protection:** 29 reconciled native-16-kHz VA1 participants (17 HC/12 PD), 81 workbook-matched native-8-kHz Figshare participants (41 HC/40 PD), plus the previously audited MDVR/UCI feature tables for separately labelled internal baselines. All new material is under `results/cross_language_generalisation_v1/`; source hashes cover 1,429 existing input/artifact files. Before/after hashes match exactly. No original audio, VA1 baseline, manifests, reconciliation or prior experiment output was modified.
- **Harmonisation:** Re-extracted both raw cohorts with a common Praat/Parselmouth candidate stable-voiced interval and identical feature implementation (75 Hz floor/500 Hz ceiling, 10 ms step, longest voiced run trimmed 10% at each edge). Core4 = median F0, local jitter, local shimmer, HNR; core5 adds F0 IQR. No feature selection or automatic exclusions. All 110 primary waveform extractions succeeded. Pitch floors 60/75/90 Hz were checked; one Figshare file failed only under 90 Hz, retained in sensitivity output. Italian originals were also polyphase-downsampled to separate 8 kHz FLOAT WAV analysis copies (29 participants).
- **Statistical comparison:** Group tests used participant-level rows and 5,000 participant bootstrap replicates; Holm correction within each dataset's five-feature family. F0 direction agreed (HC−PD negative), but effect estimates differed; F0-IQR and jitter directions disagreed; shimmer was positive in both but close to zero in Figshare; HNR was negative in both but weak in Figshare. No common-feature disease effect was convincingly replicated across cohorts. An age/sex-adjusted HC3 model was exploratory and cannot separate dataset, sample rate, device, cohort and possible language effects. Italian 16→8 kHz resampling preserved feature rankings, but HNR shifted systematically (Holm paired p≈0.00007); nominal rate matching did not make recordings equivalent.
- **Within-dataset classification:** 36 nested evaluations, outer stratified 5-fold participant splits and inner 3-fold hyperparameter search; all preprocessing/model selection inside each training fold. Highest tested Italian VA1 BAcc was 0.858 (scaled LR, core4; AUC 0.863; 17/12; BAcc prediction-bootstrap CI [0.716,0.971]). Highest Figshare BAcc was 0.679 (RF, core5; AUC 0.695; 41/40; CI [0.579,0.778]). These are selected maxima among tested configurations and exploratory; they are not directly comparable with the historical six-feature VA1 baseline.
- **Zero-shot external classification:** 24 source-only model/feature/rate-sensitivity runs; external labels were never used for preprocessing, scaling, tuning, or threshold choice. Native Italian→Figshare BAcc range 0.382–0.551 (best AUC 0.501); native Figshare→Italian BAcc range 0.277–0.569 (best AUC 0.618). Italian 8 kHz resampling did not resolve transfer: Italian-resampled→Figshare BAcc 0.382–0.538; Figshare→Italian-resampled BAcc 0.390–0.598. All target participant bootstrap intervals are in the CSV. Four sustained-vowel↔MDVR-reading directions were marked invalid and not scored. No external adaptation, pooled random split or deep model was run.
- **Dataset identity / ablation:** Exact diagnosis-count-matched 5-fold CV used 30 repeated draws (each dataset 17 HC/12 PD). Median domain BAcc was 0.672 for standardized LR, 0.707 for RBF SVM, and 0.655 for RF. A fixed standardized logistic ablation over the same 30 draws reduced median domain BAcc from 0.672 to 0.603 when removing F0 IQR and to 0.612 when removing jitter; removing median F0 slightly increased it. These are domain-associated features in this sample, not causal indicators of device or language.
- **Other within-dataset results:** MDVR read-text provisional feature baseline (21 HC/16 PD) reached a selected nested BAcc of 0.827; its candidate VAD/speaker measures remain unvalidated, so this is not treated as a reliable biomarker. UCI #174 (8 HC/24 PD) and UCI #301 vowel-specific training tasks (20/20) were evaluated separately as precomputed-feature-only classifiers. UCI #189 is PD-only; no binary classifier was run. No UCI resource was used as raw-audio validation.
- **Models/configuration:** Logistic Regression (scaled/unscaled), RBF SVM (scaled), Random Forest, balanced class weights, fixed random seed 20261031. Gradient Boosting was not added because the smallest cohort has 29 participants and five pre-specified features. No feature selection, adaptation, deep learning, or threshold tuning on target labels. Configuration and model grids are in `configs/experiment_config.json`; domain ablation settings in `configs/dataset_identity_ablation.json`.
- **Validation:** 30/30 checks passed, including metric recomputation from saved OOF/target predictions, per-fold ID disjointness, external source/test manifests, matched identity CV/ablation split audits, output files and source-hash integrity. Full test suite: 66 passed. Six figures were visually checked and are in both 320 dpi PNG and PDF. No dependencies were installed; statsmodels was absent, so the age/sex regression used the standard HC3 matrix estimator implemented with NumPy/SciPy.
- **Outputs/scripts:** `src/cross_language_generalisation/`; primary reports under `results/cross_language_generalisation_v1/` (`README.md`, compatibility, feature harmonisation, statistics, classifiers, generalisation, limitations, decisions, validation report). Participant-level tables, predictions, folds, effects, ablations, compatibility, and QC are in `tables/`. Figures are `figures/fig1`–`fig6` PNG/PDF.
- **Interpretation:** There is no useful zero-shot cross-dataset disease classifier in this task-matched but acquisition-confounded pair. Dataset origin is more predictable than diagnosis transfer in matched acoustic features. This does not establish failure of language generalisation because Figshare language is unknown. No common `/a/` feature showed stable cross-cohort disease effects; VA1 `/a/` also cannot replicate VI1 `/i/` shimmer.
